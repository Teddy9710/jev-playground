API Key 配置
每个 provider 一把 key，只存在你的浏览器 localStorage；发送时经本地服务内存转发，绝不落盘、绝不写日志。优先级：页面配置 > 环境变量（各行状态点会显示环境变量是否已设置）。对比模式下每行选手自动带各自 provider 的 key。
